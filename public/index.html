이 버전의 범위

브라우저에서 작동하는 로컬 MVP입니다. 회원가입, 서버 저장, 실제 주문, 실시간 추천은 없습니다.

일지와 학습 진도는 이 브라우저 저장소에 저장합니다. 브라우저에 따라 파일 직접 열기에서 저장이 제한될 수 있고, 데이터 삭제 시 복구할 수 없습니다.

미래 봉은 화면과 지표에서 숨깁니다. 단, 원본 데이터는 브라우저에 존재하므로 개발자 도구로 열람할 수 있습니다. 평가용 부정행위 방지는 서버 기반 데이터 제공이 필요합니다.
