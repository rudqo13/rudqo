# 차트의 이유 — Vercel 배포용

삼성전자 과거 일봉 실습 버전을 정적 웹 프로젝트로 구성했습니다. 프레임워크와 패키지 설치, 빌드, API 키는 필요하지 않습니다. 실제 Vercel 배포는 사용자가 진행해야 합니다.

## 파일 구조

```text
vercel.json
public/
  index.html
  404.html
  assets/
    styles.css
    app.js
README.md
.gitignore
```

## Vercel에 배포하기

### GitHub 연결 방식
1. ZIP을 풀고 프로젝트 파일들을 본인의 GitHub 저장소에 올립니다. ZIP 자체가 아니라 압축 해제한 내용을 올리세요.
2. 저장소 최상위에 `vercel.json`, `public` 폴더가 있도록 합니다.
3. Vercel에서 Add New → Project로 저장소를 가져옵니다.
4. Framework Preset은 **Other**, Root Directory는 `vercel.json`이 있는 폴더로 설정합니다.
5. Output Directory는 **public**입니다. Build Command와 Install Command는 사용하지 않습니다. 설정은 vercel.json에 포함되어 있습니다.
6. 환경변수는 필요하지 않습니다. Deploy를 누릅니다.
7. 배포된 주소에서 차트·매매·진도 저장을 점검합니다. 이후 연결된 브랜치에 변경 내용을 푸시하면 재배포할 수 있습니다.

### CLI 방식 (Node.js 설치 필요)

압축 해제한 프로젝트 폴더에서 실행합니다.

```bash
npx vercel login
npx vercel
# 미리보기 확인 후 운영 배포
npx vercel --prod
```

## 내 컴퓨터에서 확인

Python이 설치된 환경에서 프로젝트 폴더를 열고:

```bash
python -m http.server 8000 --directory public
```

브라우저에서 http://localhost:8000 을 엽니다. 파일 더블클릭보다 HTTP 서버로 확인하세요. CSS·JS 경로는 웹서버 루트 기준입니다.

## 배포 후 점검 목록
- 첫 실행에서 2026-02-27까지의 삼성전자 차트가 보이는지
- 선/캔들 전환, 학습 탭, 판단 일지가 작동하는지
- 판단 이유를 기록하기 전 다음 봉이 차단되는지
- 현금 시작은 매도 불가, 10주 보유 시작은 매도 가능한지
- 주문 후 다음 봉 시가 체결 및 현금 부족 시 거절되는지
- 새로고침 후 같은 도메인에서 기록이 남는지
- 모바일에서 메뉴·주문 입력창을 사용할 수 있는지

## 저장과 보안의 범위
- localStorage만 사용합니다. 로그인, 데이터베이스, 기기 간 동기화가 없습니다.
- 로컬 파일, localhost, 미리보기 URL, 운영 URL은 서로 다른 저장 공간입니다. 기존 기록은 배포 주소로 자동 이전되지 않습니다. 기존 앱에서 JSON으로 백업하세요. JSON 복원 기능은 아직 없습니다.
- 공개된 도메인을 바꾸거나 브라우저 데이터를 삭제하면 기존 진도에 접근하지 못할 수 있습니다.
- 미래 가격은 화면에서만 숨깁니다. JavaScript 파일에 전체 사례 데이터가 있으므로 개발자 도구로 확인할 수 있습니다. 시험용 차단은 서버 데이터 제공이 필요합니다.
- 현재 JS에 인라인 이벤트 핸들러가 연결되어 있으므로 엄격한 CSP를 임의로 추가하면 버튼이 동작하지 않을 수 있습니다. 보안 헤더 4종은 포함했습니다.
- 실제 주문·투자 추천·자동 손절 기능은 없습니다.

## 콘텐츠와 데이터
- 기존 버전의 삼성전자 005930 데이터(2025-11~2026-03)와 2026-02-27 시작 시나리오를 유지했습니다. 이번 배포 패키징에서 가격을 새로 조회하지 않았습니다.
- 데이터 제공 출처는 NAVER Finance / FinanceDataReader입니다. 실시간이 아니며 자동 갱신되지 않습니다. 상용 이용 및 공개 재배포 권한은 별도 확인해야 합니다. 확인 전에는 내부 테스트용으로 사용하세요.
- 존 J. 머피 교재의 공개 목차와 연결한 자체 해설입니다. 한국어판 본문 전체를 대조한 공식 요약이 아닙니다.
- 이미지 시안은 실제 차트 대신 삽입하지 않았습니다. 실제 차트는 브라우저에서 데이터로 그립니다.
